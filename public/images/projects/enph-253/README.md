## Export guidance

- Prefer WebP for photographs, plots, scope captures, and schematic crops.
- Export wide images at roughly 1600–2400 px; keep schematic text readable on a phone.
- Crop out irrelevant CAD or oscilloscope UI when it does not add measurement context.
- Keep source aspect ratios; the page uses contain-fit for technical figures so details are not cropped.
